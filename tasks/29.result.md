# TASK 29 result — React Mission Control dashboard

## Summary
Built the React Mission Control dashboard (React 19 + Vite + TypeScript) at `apps/web/`.
Connects to the actual local `/api/v1` FastAPI backend. All data is backend-derived; nothing is invented.

## Screens implemented (10 of 10)
1. **Mission Control** - system health, key metrics, recent events
2. **Attack Lab** - test agent actions against the policy gateway (guard/decide)
3. **Paired Run Comparator** - arm A vs arm B outcomes, attempted vs executed
4. **Incident Evidence Timeline** - evidence chain events with citations
5. **EVCS Containment Explorer** - containment branches (placeholder, SIMULATED label)
6. **Site Guard Scanner** - target registration (localhost-only), scan findings
7. **Fix Verification & Human Approval** - pending fix proposals with state labels
8. **Live Shield** - active shield rules with TTL, TEMPORARY SHIELD labeling
9. **Escalation Inbox** - escalation tickets awaiting human review
10. **Evaluation Metrics & Reports** - metrics with numerators/denominators, report export
